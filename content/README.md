# 内容填写指南

这个文件夹是你和网站之间的"交接区"。你只管在这里放素材、填文字，
填好后告诉我一声「接入 content」，我会把内容接进网站并调好版式。

## 目录结构

```
content/
├── README.md            ← 本说明
├── about.md             ← 关于你/工作室的全部文字（左栏内容）
└── projects/            ← 每个作品一个文件夹
    └── 01-示例项目/
        ├── info.md      ← 这个作品的文字信息（标题、介绍等）
        ├── cover.png    ← 缩略图（中间编号列用，方形最佳）
        └── images/      ← 详情大图，按文件名顺序展示
            ├── 01.jpg
            └── 02.jpg
```

## 操作步骤

1. **添加作品**：复制 `projects/01-示例项目` 整个文件夹，改名为 `02-你的项目名`，
   替换里面的图片，按 `info.md` 里的说明填好文字。
   想删哪个作品就直接删掉对应文件夹；想调整顺序就改文件夹名前面的编号。
2. **填写关于页**：打开 `about.md`，把示例文字换成你自己的。
   不需要的版块整段删掉即可。
3. **告诉我接入**：在对话里说一声「接入 content」，剩下的交给我。

## 图片要求

| 用途 | 位置 | 建议 |
| --- | --- | --- |
| 缩略图 | 项目文件夹里的 `cover.png`（jpg 也可以） | 方形，600×600 以上，画面主体居中 |
| 详情图 | 项目文件夹的 `images/` | jpg / png，宽 1200–2500px，单张 5MB 以内 |
| 视频（可选） | 项目文件夹的 `images/` | mp4，会和图片一起出现在右侧滚动区 |

## 分类标签（顶部筛选条）

目前网站有 6 个分类，填 `info.md` 的「分类」时从这里选（可多个）：

- `VISUAL IDENTITY`（视觉识别）
- `PACKAGING`（包装）
- `BOOK`（书籍）
- `KEY VISUAL`（主视觉）
- `DIGITAL`（网站/数字）
- `INSTALLATION & DISPLAY`（装置与展示）

想新增或改名分类也可以，直接在 `info.md` 里写你想要的名字，我会同步调整筛选条。

## 常见问题

- **文字里想加斜体/加粗？** 用 `*斜体*` 和 `**加粗**` 标记，我会转换。
- **中英混排？** 直接混写即可，排版规则我来处理。
- **改错了想恢复？** 项目有 git 版本记录，随时可以回退，放心改。
